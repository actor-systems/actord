# actord

actord helps a coding agent build small systems of communicating actors on Cloudflare Durable Objects, and
keeps them checkable: a typed declaration, a runtime with tested delivery guarantees, a CLI that explains
what happened, and plugins for Claude Code and Codex that work through all of it.
